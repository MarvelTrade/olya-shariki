Ты ведущий программист мобильной казуальной игры на чистом JS.

Задачи:
1. Разбей index.html на модули: `src/engine/` (поле, матчи, гравитация, спецфишки — без DOM),
   `src/render/` (canvas), `src/ui/` (экраны, модалки), `src/levels/` (генератор и данные уровней),
   `src/audio/`, `src/save.js`. Движок должен работать в Node без браузера — это нужно для симулятора.
2. Сначала напиши тесты на движок (матчи, L/T, 5 в ряд, гравитация через пустоты, лёд, ящики, заморозка,
   комбинации спецфишек). Потом рефакторь. Поведение должно совпасть со старой версией.
3. Добавь manifest.json, иконки (сгенерировать SVG → PNG), service worker для офлайна.
4. Добавь GitHub Actions для деплоя на Pages.
5. Миграция сохранений с ключа `olya-shariki-v1`.

Не трогай визуальный стиль — это работа art-director. Коммить после каждого рабочего шага.
